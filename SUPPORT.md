# Support

- Use [GitHub Discussions](https://github.com/volter-ai/widget-shell/discussions) for usage questions and design discussion.
- Use [GitHub Issues](https://github.com/volter-ai/widget-shell/issues) for reproducible bugs and accepted feature proposals.
- Use the private process in `SECURITY.md` for vulnerabilities.

Before `0.1.0`, APIs may change without a migration period. Maintainers prioritize security, correctness, accessibility, browser compatibility, and the documented product boundary over feature volume.
